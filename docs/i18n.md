# Internationalization (i18n)

Requires `i18n` feature (Fluent).

## Setup

```toml
[dependencies]
burin = { git = "...", features = ["i18n"] }
```

Place `.ftl` files in `locales/`:

```
locales/
  en-US/
    main.ftl
  zh-CN/
    main.ftl
```

```
# main.ftl
hello = Hello, {$name}!Welcome back. You have {$count} new messages.
```

## Usage

```rust
use burin::t;

// t! macro: reads from Fluent bundle
let greeting = t!(ctx, "hello", name = "Alice");       // Signal<String>
let welcome = t!(ctx, "welcome-back", count = 5);        // Signal<String>

// Bind to a Text widget
Text::new("").bind(greeting);

// Switch locale at runtime
ctx.set_locale("zh-CN");
```
